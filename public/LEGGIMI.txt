ORARIO LAB — COPIA STATICA

Carica tutti i file di questa cartella su un web server statico, anche in una sottocartella.
Apri index.html attraverso HTTP o HTTPS, non con un doppio clic sul file.
Non servono Node.js, database, installazioni di dipendenze o compilazioni.
Non sono presenti /admin, login, API o collegamenti a servizi remoti.

AGGIORNAMENTO
Sostituisci orario.csv con il CSV esportato da Google Fogli (UTF-8, separatore virgola).
Mantieni 37 colonne: nome, Colore e 7 colonne per ognuno dei cinque giorni.
Le righe finali sono Settimana dispari, Settimana pari e Note.
La settima colonna vuota per tutte le righe determina un giorno di sei ore.
Modifica config.json con un editor di testo: csvFile, csvHasHeader, timeZone e days.
starts contiene gli inizi; end la fine dell'ultima ora configurata.
Se config contiene 7 inizi ma il CSV indica 6 ore, il sesto periodo termina all'inizio del settimo.
Se il CSV passa a 7 ore, configura il settimo inizio e la nuova fine lezioni.
Ricarica la pagina dopo aver sostituito i file. CSV e JSON sono richiesti senza cache del browser;
un eventuale CDN o proxy deve essere configurato per non fornire copie obsolete.
Il pulsante Adesso aggiorna la selezione del giorno, non rilegge i file.

SERVER LOCALE
Se Python è installato, da questa cartella esegui: python -m http.server 8000
Poi apri http://localhost:8000
In alternativa usa IIS, Apache, Nginx o qualsiasi hosting statico.

Questa versione conserva la grafica e la consultazione dell'orario.
Non include ancora manifest o service worker PWA.

SETTIMANE PARI/DISPARI E NOTE
Le righe finali sono Settimana dispari, Settimana pari e Note. Note può essere omessa se non serve.
Mantieni 37 colonne anche per Note: nome, Colore vuoto, 35 celle per le ore.
La settimana che contiene il primo gennaio è la 1, le successive iniziano lunedì.
Il conteggio riparte il primo gennaio, usando il fuso orario di config.json.
Settimana D/mon - D/mon · pari/dispari mostra le date del lunedì e venerdì correnti e resta fissa sotto i giorni durante lo scroll. Per ogni ora la settimana corrente è in cima.
Ogni occupazione ha etichetta P (pari) o D (dispari), a destra e centrate verticalmente dentro il box occupazione, senza separatore verticale. Senza alternanza compare P/D. L'altra occupazione è sotto, con sfondo verde chiaro e testo nero. I colori delle classi restano invariati.
Le etichette delle classi mantengono i colori dei docenti.
Solo l'occupazione in corso è verde scuro.
Vuoto = Libero; M = manutenzione / pulizia, indipendentemente per ogni riga.
Una x (anche X) in Settimana pari disattiva l'alternanza: si mostra solo Settimana dispari per entrambe le settimane, con etichetta Pari e dispari · Alternanza non prevista.
Non esiste più alcuna gestione speciale delle date nelle righe Lab.
Il testo di Note viene mostrato in basso nel riquadro verde della settimana corrente, una volta per ora, anche quando c'è x.
Le note non aggiungono ore: il numero di ore dipende dalle righe docenti e Lab.
Il CSV incluso è la copia precedente con una riga Note vuota aggiunta e le due vecchie date in Settimana pari sostituite con x: sostituiscilo con la tua esportazione aggiornata.

MENU ACCOUNT
Il menu in alto a destra contiene Logout, collegato a /cdn-cgi/access/logout sul dominio del sito.
Il collegamento richiede Cloudflare Access configurato sull'host: su un server locale non effettua alcun logout.
